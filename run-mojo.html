pipeline:run

Full name:

org.honton.chas:pipeline-maven-plugin:0.0.1:run

Description:

(no description)

Attributes:

  • Requires a Maven project to be executed.
  • The goal is thread-safe and supports parallel builds.
  • Binds by default to the lifecycle phase: verify.

Required Parameters

Name Type Since Description
<steps> List<Step> - Pipeline steps

Optional Parameters

Name Type Since Description
<dir> String - Working directory of pipeline
<skip> boolean - Skip pipeline goal
Default value is: false.
User property is: pipeline.skip.
<stdIn> String - Optional input file to pipeline. Defaults to empty stream.
<stdOut> String - Optional output file for pipeline. Defaults to maven logger.
<wait> String - Duration to wait for completion of pipeline. Duration is positive integer followed by unit indicator. Unit can be 'h' (hours), 'm' (minutes), or 's' (seconds).
Default value is: 5m.
